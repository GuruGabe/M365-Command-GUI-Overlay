  CHANGELOG - M365GUI

10-23-2026  v0.5  INSTALLERS FOR WINDOWS, MACOS AND LINUX; UPDATES ITSELF.
                  - Every release now has an installer and a portable copy
                    for each system, like GAMGUI: Windows Setup.exe
                    (Program Files, Start Menu and desktop shortcuts,
                    Add/Remove Programs) and zip; macOS .dmg and zip;
                    Linux .deb, .rpm and tar.gz. The SHA-256 of each file
                    is in the release notes.
                  - Help > Check for updates now, and a check at startup
                    (can be switched off). M365GUI asks first, then
                    installs only a download whose SHA-256 matches the
                    release notes, and restarts itself. A portable copy
                    keeps its settings and logs.
                  - Help > What's new shows the changes - and opens once by
                    itself after an update (can be switched off).
                  - An installed copy keeps its settings and logs in a
                    per-user folder (Program Files and /opt are read-only):
                    %LOCALAPPDATA%\M365GUI, ~/Library/Application
                    Support/M365GUI or ~/.local/share/M365GUI.
                  - macOS / Linux: m365 and Node.js are found in their usual
                    folders even when the app is started from Finder or a
                    menu (no Terminal PATH).
                  - Tests: tests\test_v05_installers.py.
10-22-2026  v0.4  ONEDRIVE: COPY A USER'S FILES TO ANOTHER USER; NO SHELL.
                  - New OneDrive section:
                    - 'Copy a user's OneDrive files to another user' - for
                      a leaver: copies everything into a new folder in the
                      recipient's OneDrive. Nothing is removed from the
                      leaver; same-name files are renamed, never
                      overwritten. Shows the file count and size, asks
                      Yes/No once, then counts the files that arrived and
                      saves a CSV record (Logs\OneDrive-Copy_*.csv). The
                      admin is made site admin of both OneDrives for the
                      run; only the access M365GUI added is removed again
                      (or kept, if chosen). Stop ends it after the current
                      item and still removes the access.
                    - 'Find a user's OneDrive address'.
                  - SECURITY FIX: commands no longer go through cmd.exe.
                    m365.cmd passed every value to cmd.exe, which treated
                    '&' (and | < > ^) as the start of ANOTHER command - a
                    value 'a&echo.x' ran 'echo.x' (checked live 10-22-2026).
                    A display name, group or file/folder name with '&'
                    could run something on the admin's PC. M365GUI now
                    starts node with the CLI's own script directly. On an
                    install where that script is not found it still uses
                    m365.cmd but refuses such values.
                  - No console window flashes up for each command, and a
                    question from the CLI can no longer leave a task
                    hanging (commands get an empty input).
                  - Tests: tests\test_onedrive_transfer.py (fake m365, 31
                    checks), tests\test_invocation.py.
08-07-2026  v0.3  DEPLOY FIX: the build no longer ships the Tcl encoding
                  files (_internal\_tcl_data\encoding\*.enc). Endpoint
                  security (e.g. CrowdStrike) blocks the .enc extension - it
                  looks like ransomware output - so copying the app to other
                  machines failed with "permission denied" for every account.
                  Tcl 9 keeps these encodings inside the DLL and falls back
                  to them, so extract_tcl.py now removes the loose .enc files.
                  Verified 0 .enc shipped and the app runs normally.
08-07-2026  v0.2  Expanded catalog to 33 tasks across 7 categories, all
                  verified against CLI for Microsoft 365 v11 with
                  "m365 <command> --help":
                  - Users: list, list guests, get, create, reset password,
                    rename, set usage location, block/unblock sign-in, delete,
                    list deleted (recycle bin), restore deleted, and a guided
                    "Remove ALL guest users" workflow (list -> type DELETE ->
                    remove each).
                  - Groups: list, list by type, get info, create, list members,
                    add/remove member, delete.
                  - Licenses: view all tenant SKUs, list users with a specific
                    license, assign, remove.
                  - Teams/SharePoint/Security/Diagnostics tasks.
                  Fixes: runner now launches m365.cmd via cmd.exe and m365.ps1
                  (nvm) via PowerShell; template engine's optional [--flag]
                  segments no longer collide with JMESPath [...] in --query;
                  nonzero exits show a "re-run with --debug" tip (m365 often
                  reports "Error: [object Object]").
08-07-2026  v0.1  Initial prototype. GUI front-end for the CLI for Microsoft
                  365 built on the same engine as GAMGUI; representative task
                  set across Users, Groups, Licenses, Teams, SharePoint,
                  Security, Diagnostics.
